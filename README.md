\## 📖 What is This Project?



\*\*My Dream Home Planner\*\* is a beautiful, interactive web application that helps users visualize their dream home before construction begins!



\### ✨ Features



| Feature | Description |

| :--- | :--- |

| 🏠 \*\*House Size Selection\*\* | Choose from Small, Medium, or Big houses |

| 🚪 \*\*Door Placement\*\* | Select which directions (North, South, East, West) have doors |

| 💰 \*\*Budget Planning\*\* | Enter your construction budget |

| 📅 \*\*Duration Setting\*\* | Set your project timeline (in months) |

| 🚫 \*\*Restricted Areas\*\* | Mark any no-go zones for construction |

| 📐 \*\*2D Plan Preview\*\* | See your house plan as a 2D drawing |

| 🏠 \*\*3D House Viewing\*\* | Interactive 3D model from Sketchfab |

| 🎨 \*\*Color Customization\*\* | Change the border color of your 3D house! |



\---



\## 🎯 How It Works



\### Step 1: Fill in Your Details

1\. Choose your \*\*House Size\*\* (Small/Medium/Big)

2\. Select \*\*Door Directions\*\* (North/South/East/West)

3\. Enter your \*\*Budget\*\* (in ₹)

4\. Set your \*\*Project Duration\*\* (in months)

5\. Add any \*\*Restrictions\*\* (optional)



\### Step 2: View Your 2D Plan

\- Click \*\*"SHOW MY PLAN"\*\*

\- See your 2D house plan with all details

\- Review your choices



\### Step 3: Explore Your 3D House

\- Click \*\*"YES, Build This House!"\*\*

\- View your \*\*interactive 3D house\*\* from Sketchfab

\- \*\*Drag and rotate\*\* to see every angle!

\- \*\*Change colors\*\* with the color buttons below!
